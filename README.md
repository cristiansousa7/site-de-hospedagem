# 🌐 AlfaTech - Soluções em Hospedagem

Projeto prático desenvolvido para o curso de **HTML & CSS Avançado**. O objetivo é criar um website institucional moderno e responsivo para um provedor de hospedagem web fictício (*AlfaTech*).

---

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico**: Estruturação com tags semânticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<table>`, `<footer>`).
- **CSS3 Moderno**:
  - Variáveis CSS (`:root`) para padronização de cores e tipografia.
  - **Flexbox** e **CSS Grid** para alinhamentos e grids responsivos.
  - Tipografia com a fonte **Poppins** (Google Fonts).
  - Design limpo com sombras suaves e microinterações no `:hover`.
  - Tabelas zebradas e estilizadas.
  - **Design Responsivo** com Media Queries para visualização em desktops, tablets e smartphones.

---

## 📂 Estrutura de Arquivos

```text
├── index.html           # Página inicial institucional com banner, diferenciais e planos
├── precos.html          # Página comparativa detalhada de recursos e preços
├── style.css            # Estilos gerais, cabeçalho, hero banner e home
├── precos.css           # Estilos dedicados à tabela detalhada de preços
├── README.md            # Documentação do repositório
└── *.png                # Imagens e ícones utilizados no projeto
```

---

## 💻 Como Visualizar Localmente

1. Clone este repositório ou baixe os arquivos em ZIP.
2. Dê dois cliques no arquivo `index.html` para abrir diretamente no seu navegador web.
3. Não é necessária nenhuma instalação ou servidor para rodar o projeto.
